osm2svg4opcd (v7.0)

OpenStreetMap to SVG Converter for Open Platform Course Design (OPCD)

A specialized GIS-to-SVG engine designed to create high-fidelity, scale-accurate map data for golf course simulation. This tool bridges the gap between raw OpenStreetMap data, QGIS imagery, and the Blender (Clender) workflow.

🚀 Key Features

  • Automated Background Alignment New: Uses rasterio to reproject and clip GeoTIFFs (Google/Bing) into the map’s WGS84 coordinate space.
  • Unitless Scaling: Switched from explicit mm units to SVG User Units to resolve the 96 DPI (3.78x) scale mismatch.
  • Proximity Building Filter: Automatically identifies leisure: golf_course boundaries and filters out buildings that fall outside the simulation area.
  • Z-Order Path Clipping: Higher-priority features (bunkers/paths) "clip" geometry beneath them (fairways/rough) to prevent mesh overlapping.
  • Scale Accuracy: Strictly maintains a 1 unit = 1 meter relationship.

📐 Core Concepts

1. The "Cookie Cutter" Raster Logic

The tool creates a temporary _aligned.png by defining a target grid based on the MIN/MAX Lon/Lat of your map.osm. It reprojects pixels from your source GeoTIFF into a "Flat-Degree" (EPSG:4326) grid, ensuring perfect alignment with vector data.

2. Styles and Z-Ordering (styles.json)

The rendering engine uses a centralized configuration to handle:

  • z-order: Higher numbers = Foreground.
  • clipper-mode: default or unbreakable for complex intersections.
  • fill-rule: Utilizes evenodd for complex MultiPolygon relations.

🛠 Usage Workflow

Step 1: Generate Aligned SVG

python3 osm2svg_v7.py --background1="/path/to/your/QGIS_Export.tif"

Input: map.osm, styles.json, scale_config.txt, *.tif
Output: out.svg, *_aligned.png

Step 2: Path Optimization

python3 svg_points2path.py

Converts polylines to optimized <path> structures to resolve "Color Errors" in Clender.

📝 Configuration Files

File Purpose
styles.json Feature identification, colors, and Z-order.
scale_config.txt Global scale (default 1000 for 1:1000 scale).
map.osm Source WGS84 vector data.
